# LampRead

A better markdown reader with a built-in editor.

Read comfortably, highlight words, sentences and paragraphs, and edit right in the text whenever you feel like it.

## What can it do?

- **Read** markdown files in a clean, calm view
- **Highlight** words, sentences or paragraphs so you can come back to them later
- **Edit** the text directly, without switching apps

## Status

Work in progress. A first version is on its way.

## Plans

- Run on newer iPhones
- Save and collect your highlights

## Getting started

Coming soon, once there is something to run.

## Background

LampRead started as a way to read self-written stories aloud to children, but it's meant to be a reader for any markdown text.
